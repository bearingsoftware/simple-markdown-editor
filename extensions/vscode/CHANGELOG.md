# Changelog

## 0.1.1

- Files in a WSL window open in Simple Markdown Editor through `\\wsl.localhost\<distro>`. The extension
  runs on the UI side, so it loads in WSL windows.
- WSL files are not restored after a restart and are not listed in Open Recent.

## 0.1.0

- Open in Simple Markdown Editor for `.md` and `.markdown` files, including multi-select.
- Open Recent from Simple Markdown Editor.
- `mdedit.executablePath` setting for installs the extension cannot find.
